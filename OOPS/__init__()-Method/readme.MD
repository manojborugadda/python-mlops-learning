#  __init__() Method

- In Python, the `__init__()` method is a special method that is automatically called when a new instance of a class is created. 
- It is used to initialize the attributes of the object with specific values.
- The __init__() method is CALLED  automatically every time the class is being used to create a new object.

# Why Use __init__()?

Using the `__init__()` method ensures that the object is properly initialized with the required attributes and values. This makes the code more organized, maintainable, and less prone to errors.
